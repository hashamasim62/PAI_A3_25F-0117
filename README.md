# PAI-A3-25F-0117 - Programming for AI, Assignment 3

## How to run
1. Clone the repo and keep the files in `data/` unchanged.
2. Install dependencies: `pip install numpy pandas matplotlib jupyter`
3. Open `Assignment3_Programming_for_AI.ipynb` in Jupyter.
4. Run all cells from top to bottom (Kernel > Restart and Run All).
5. Outputs (`dashboard.png`, `dashboard.pdf`, `wave.gif`) are saved to `outputs/`.

Only numpy, pandas, matplotlib and the standard library are used.
